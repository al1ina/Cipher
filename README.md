# 🔐 Cipher Encoder (Caesar & One-Time Pad)

This project is a simple yet educational **cryptography application** that allows users to encode and decode messages using two classic ciphers:  

- **Caesar Cipher** → All letters are shifted by the same amount (the key).  
- **One-Time Pad Cipher** → Each letter is shifted by a random key, making it far more secure.  

The application provides both **functionality** and an **interactive GUI**, making cryptography easy to learn and experiment with.  

---

## ✨ Features
- Caesar cipher implementation with configurable shift key.  
- One-time pad cipher with randomly generated keys.  
- Automatic wrap-around logic for alphabet boundaries.  
- Case-sensitive handling (uppercase/lowercase preserved).  
- Clean and intuitive **GUI built with WindowBuilder**:
  - Input field for messages  
  - Key input (for Caesar cipher)  
  - Buttons to **Encrypt** and **Decrypt** messages  
  - Output display
